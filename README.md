# AURELIA 50 — motor superyacht

Scroll-driven, minimal premium site for a 50 m motor superyacht: aerial hero video, silhouette, under way, decks, sundeck, beach club, salon, owner's suite, night finale.

Static site, no build step. Deploy on Vercel with framework preset **Other** (output = repo root).

- `index.html` — the whole site (HTML, CSS, JS)
- `img/` — renders and video posters (WebP)
- `video/` — clips (H.264 MP4, 1080p)

Renders are AI-generated (Figma AI), clips generated in Kling from those renders. Specs, prices and copy are demo content.
